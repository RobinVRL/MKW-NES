# Item map markers

`cook_race_map.py` uses these eight small PNGs to build the lower-screen race map atlas:

```
map_banana.png   map_bomb_hei.png  map_exp_b.png   map_exp_r.png
map_kame_g.png   map_kame_r.png    map_kame_wing.png  map_start.png
```

**They aren't included in this repository** because they're Nintendo art. Copy
them from the upstream [MKW-3DS](https://github.com/MiniBandit/MKW-3DS) builder
(`tools/release/mk7_markers/`), or draw your own replacements with the same
file names. No MK7 cartridge image is needed. All other resources are
generated from your own Wii disc.
